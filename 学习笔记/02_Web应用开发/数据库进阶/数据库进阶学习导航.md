# 数据库进阶学习导航

数据库进阶用于整理数据库基础语法之后的底层原理、性能优化和运维相关知识。

## 1. 学习顺序

```text
存储引擎 → 索引原理与优化 → SQL优化 → 锁 → InnoDB核心原理 → MySQL管理
```

# 数据库学习导航

数据库是独立的学习专题，也是理解FastAPI数据库操作和ORM的基础。

## 1. 学习顺序

```text
数据库基础概念 → 安装并准备MySQL → SQL基础语法 → MySQL数据类型 → DDL → MySQL约束 → DML → DQL → 多表查询 → MySQL函数 → DCL → 事务 → 索引 → Python连接数据库与ORM
```

1. [[数据库基础概念]]：分清数据库、DBMS和SQL，了解常见关系型数据库。
2. [[Windows下载、安装与登录MySQL]]：只在下载、安装、重新配置或登录MySQL时查看。
3. [[SQL基础语法]]：掌握SQL书写规则、注释以及DDL、DML、DQL和DCL的区别。
4. [[MySQL数据类型]]：选择数值、字符串、二进制和日期时间类型。
5. [[DDL数据库与表结构操作]]：创建、查询、修改和删除数据库、数据表及字段。
6. [[MySQL约束]]：使用非空、唯一、主键、默认、检查和外键规则限制数据。
7. [[DML数据操作]]：新增、修改和删除数据表中的记录。
8. DQL数据查询：
   - [[DQL基本查询]]：查询结构、指定字段、全部字段、别名和去重。
   - [[DQL条件查询]]：使用`WHERE`和各种运算符筛选记录。
   - [[DQL分组查询]]：聚合函数、`GROUP BY`和`HAVING`。
   - [[DQL排序查询]]：使用`ORDER BY`进行单字段和多字段排序。
   - [[DQL分页查询]]：使用`LIMIT`限制和分页返回记录。
9. 多表查询：
   - [[多表查询概述]]：笛卡尔积以及连接查询、子查询的分类。
   - [[多表关系]]：表之间的一对多、多对多和一对一关系。
   - [[内连接]]：使用隐式或显式写法查询两张表中满足关联条件的数据。
   - [[外连接]]：使用左外连接或右外连接保留指定一侧的全部数据。
   - [[自连接]]：使用不同表别名查询同一张表中记录之间的关系。
   - [[联合查询]]：使用`UNION`或`UNION ALL`纵向合并多次查询的结果。
   - [[子查询]]：在SQL语句中嵌套查询，并根据结果形状和书写位置分类。
10. MySQL函数：
   - [[MySQL字符串函数]]：字符串的拼接、转换、填充、清理和截取。
   - [[MySQL数值函数]]：数值的取整、求余、随机数和四舍五入。
   - [[MySQL日期函数]]：日期时间的获取、提取、增加和间隔计算。
   - [[MySQL流程函数]]：使用`IF`、`IFNULL`和`CASE`进行条件判断。
11. [[DCL权限控制]]：数据库用户和访问权限控制。
12. 事务：
   - [[事务概述与操作]]：通过自动提交设置或显式开启事务，统一提交或回滚一组操作。
   - [[事务四大特性]]：原子性、一致性、隔离性和持久性。
   - [[并发事务问题]]：脏读、不可重复读和幻读的产生过程及区别。
   - [[事务隔离级别]]：四种隔离级别、并发问题对照以及查看和设置方法。
13. 索引：用于加快数据查询。
14. [[FastAPI数据库与ORM]]：把数据库知识用于Python和FastAPI项目。

完成基础内容后，可以继续学习[[数据库进阶学习导航|数据库进阶]]。

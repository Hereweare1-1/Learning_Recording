# 数据库学习导航

数据库是独立的学习专题，也是后续学习FastAPI数据库操作和ORM的基础。

## 1. 当前学习顺序

```text
数据库基础概念 → 安装并准备MySQL → SQL基础语法 → MySQL数据类型 → DDL → DML → DQL → DCL → 索引与事务 → Python连接数据库与ORM
```

1. [[数据库基础概念]]：分清数据库、DBMS和SQL，了解常见关系型数据库。
2. [[Windows下载、安装与登录MySQL]]：只在下载、安装、重新配置或登录MySQL时查看。
3. [[SQL基础语法]]：掌握SQL书写规则、注释以及DDL、DML、DQL和DCL的区别。
4. [[MySQL数据类型]]：选择数值、字符串、二进制和日期时间类型。
5. [[DDL数据库与表结构操作]]：创建、查询、修改和删除数据库、数据表及字段。
6. [[DML数据操作]]：新增、修改和删除数据表中的记录。
7. [[DQL数据查询]]：从基本查询开始，后续补充条件、排序、分组和多表查询。
8. [[DCL权限控制]]：了解数据库用户和访问权限控制。
9. 索引与事务：在掌握基本SQL后再学习，不提前展开底层原理。
10. [[FastAPI数据库与ORM]]：最后把数据库知识用于Python和FastAPI项目。

## 2. 当前学习重点

- **重点掌握**：MySQL基本使用、SQL增删改查、条件查询、多表查询、常见约束和事务基础。
- **会用即可**：索引的基本使用、Python连接数据库、通过ORM完成常见操作。
- **了解即可**：不同DBMS的定位以及当前阶段用不到的底层存储原理。

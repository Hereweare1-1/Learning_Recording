# 数据库学习导航

数据库是独立的学习专题，也是后续学习FastAPI数据库操作和ORM的基础。

## 1. 当前学习顺序

```text
数据库基础概念 → 安装并准备MySQL → SQL基础语法 → MySQL数据库操作 → 查询与多表关系 → 索引与事务 → Python连接数据库与ORM
```

1. [[数据库基础概念]]：分清数据库、DBMS和SQL，了解常见关系型数据库。
2. [[Windows安装MySQL并创建数据库]]：只在搭建或重新配置MySQL环境时查看。
3. [[SQL基础语法]]：掌握SQL书写规则、注释和常见语句分类。
4. [[MySQL数据库操作]]：查询、创建、选择和删除数据库。
5. 查询与多表关系：后续学习条件查询、分组、连接和表关系时再补充。
6. 索引与事务：在掌握基本SQL后再学习，不提前展开底层原理。
7. [[FastAPI数据库与ORM]]：最后把数据库知识用于Python和FastAPI项目。

## 2. 当前学习重点

- **重点掌握**：MySQL基本使用、SQL增删改查、条件查询、多表查询、常见约束和事务基础。
- **会用即可**：索引的基本使用、Python连接数据库、通过ORM完成常见操作。
- **了解即可**：不同DBMS的定位以及当前阶段用不到的底层存储原理。

## 3. 新增笔记规则

以后每学完一个完整主题，再建立对应笔记并加入导航，不提前创建空白笔记。

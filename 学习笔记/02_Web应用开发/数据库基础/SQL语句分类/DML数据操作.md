# DML数据操作

DML（Data Manipulation Language，数据操作语言）用于新增、修改和删除数据表中的记录，常见关键字包括`INSERT`、`UPDATE`和`DELETE`。

## 1. 语句汇总

| 作用 | 基本语句 |
| --- | --- |
| 新增数据 | `INSERT INTO 表名 (字段列表) VALUES (值列表);` |
| 修改数据 | `UPDATE 表名 SET 字段 = 值 WHERE 条件;` |
| 删除数据 | `DELETE FROM 表名 WHERE 条件;` |

## 2. INSERT：新增数据

### 2.1 给指定字段添加一条数据

```text
INSERT INTO 表名 (字段1, 字段2, ...)
VALUES (值1, 值2, ...);
```

例如：

```sql
INSERT INTO employee (name, job, dept_id)
VALUES ('小明', '开发', 1);
```

这条语句会向`employee`表中新增一条员工记录。只需要给列出的字段提供值，没有列出的字段需要允许使用默认值或`NULL`。

### 2.2 给全部字段添加一条数据

省略字段列表时，需要按照数据表定义字段的顺序，为全部字段提供值：

```text
INSERT INTO 表名
VALUES (值1, 值2, ...);
```

例如，`employee`表的字段顺序为`id`、`name`、`job`、`dept_id`：

```sql
INSERT INTO employee
VALUES (1, '小明', '开发', 1);
```

这种写法依赖数据表当前的字段数量和顺序。实际项目中优先明确写出字段列表，表结构发生变化时更不容易出错。

### 2.3 批量添加多条数据

给指定字段批量添加数据：

```text
INSERT INTO 表名 (字段1, 字段2, ...)
VALUES
    (值1, 值2, ...),
    (值1, 值2, ...),
    (值1, 值2, ...);
```

例如：

```sql
INSERT INTO employee (id, name, job, dept_id)
VALUES
    (2, '小红', '测试', 1),
    (3, '小刚', '开发', 2);
```

也可以省略字段列表并按照表中的全部字段顺序批量添加：

```text
INSERT INTO 表名
VALUES
    (值1, 值2, ...),
    (值1, 值2, ...);
```

### 2.4 注意事项

> [!warning]
> - 字段顺序必须与对应值的顺序一致，字段数量也必须与每组值的数量一致。
> - 字符串和日期类型的值通常需要放在单引号中，普通数值不需要引号。
> - 插入的数据必须符合字段的数据类型和允许范围。
> - 批量插入时，每一组值都必须拥有相同的数量。
> - 实际项目中优先写出字段列表，不要过度依赖数据表中的字段顺序。

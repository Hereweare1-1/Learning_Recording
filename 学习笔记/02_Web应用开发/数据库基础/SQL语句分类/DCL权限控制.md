# DCL权限控制

DCL（Data Control Language，数据控制语言）用于管理数据库用户和访问权限。

## 1. 语句汇总

| 作用 | 基本语句 | 当前学习状态 |
| --- | --- | --- |
| 给用户授予权限 | `GRANT 权限 ON 数据库.数据表 TO 用户;` | 了解即可 |
| 收回用户的权限 | `REVOKE 权限 ON 数据库.数据表 FROM 用户;` | 了解即可 |

## 2. 当前需要掌握什么

DCL现阶段了解用途即可，不提前学习复杂的用户、角色和权限配置语法。以后学习数据库安全或部署时再补充具体命令。

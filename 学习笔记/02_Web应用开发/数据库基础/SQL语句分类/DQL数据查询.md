# DQL数据查询

DQL（Data Query Language，数据查询语言）用于查询数据表中的记录，核心关键字是`SELECT`。

## 1. 语句汇总

| 作用 | 基本语句 | 当前学习状态 |
| --- | --- | --- |
| 查询指定字段 | `SELECT 字段名 FROM 表名;` | 正在学习 |

## 2. SELECT：查询数据

```sql
SELECT id, name
FROM employee;
```

这条语句会查询`employee`表中的`id`和`name`字段。

`SELECT`是实际开发中使用非常频繁的SQL语句。查询条件、排序、分组和多表查询等内容，学到对应主题后再补充。

## 3. 当前需要掌握什么

现阶段先掌握`SELECT 字段名 FROM 表名;`的基本结构，能够查询指定表中的指定字段。

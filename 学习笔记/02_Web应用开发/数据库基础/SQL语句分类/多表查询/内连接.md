# 内连接

内连接只返回两张表中满足关联条件的记录，可以理解为查询两张表的交集部分。不满足关联条件的记录不会出现在结果中。

## 1. 隐式内连接

隐式内连接把多张表写在`FROM`后面，并在`WHERE`中设置关联条件。

```text
SELECT 字段列表
FROM 表1, 表2
WHERE 表1.关联字段 = 表2.关联字段;
```

例如，查询员工及其所属部门：

```sql
SELECT employee.id,
       employee.name,
       department.name AS department_name
FROM employee, department
WHERE employee.department_id = department.id;
```

如果省略`WHERE`中的关联条件，两张表的记录会直接组合，产生笛卡尔积。

## 2. 显式内连接

显式内连接使用`JOIN ... ON ...`说明连接的表和关联条件。

```text
SELECT 字段列表
FROM 表1
[INNER] JOIN 表2 ON 表1.关联字段 = 表2.关联字段;
```

方括号表示`INNER`可以省略，实际书写SQL时不需要输入方括号。`JOIN`与`INNER JOIN`在这里作用相同。

使用表别名可以简化字段写法：

```sql
SELECT e.id,
       e.name,
       d.name AS department_name
FROM employee AS e
INNER JOIN department AS d
    ON e.department_id = d.id;
```

## 3. 使用要点

- `ON`主要用于指定两张表如何关联，`WHERE`可以继续筛选连接后的结果。
- 多张表中存在同名字段时，应使用`表名.字段名`或`表别名.字段名`明确字段来源。
- 为表设置别名后，后续字段引用应使用该别名。
- 没有匹配部门的员工不会出现在上面的内连接结果中，包括`department_id`为`NULL`的员工。
- 隐式和显式内连接可以得到相同结果；显式写法能更清楚地区分关联条件和普通筛选条件。

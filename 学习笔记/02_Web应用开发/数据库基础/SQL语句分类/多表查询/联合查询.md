# 联合查询

联合查询使用`UNION`或`UNION ALL`把多次查询的结果纵向合并，形成一个新的查询结果集。

连接查询根据关联条件横向组合多张表的字段；联合查询则把结构相同的多组查询结果继续向下排列。

## 1. 基本语法

```text
SELECT 字段列表
FROM 表A
...
UNION [ALL]
SELECT 字段列表
FROM 表B
...;
```

`ALL`写在`UNION`后面。方括号表示`ALL`可以省略，实际书写SQL时不需要输入方括号。

联合查询不限制只能合并两次查询，可以继续添加多个`UNION`或`UNION ALL`。

## 2. UNION与UNION ALL的区别

| 写法 | 作用 |
| --- | --- |
| `UNION` | 合并查询结果，并删除完全重复的记录 |
| `UNION ALL` | 合并查询结果，保留所有记录，包括重复记录 |

`UNION ALL`不需要执行去重操作，因此在不需要去重时通常更直接。

## 3. 联合查询的要求

- 每条`SELECT`查询返回的字段数量必须相同。
- 对应位置的字段类型应当相同或相互兼容。
- 合并时按照字段的位置对应，不是按照字段名称对应。
- 最终结果的字段名称由第一条`SELECT`决定。

例如，第一条查询和第二条查询都返回两个字段：

```sql
SELECT name AS employee_name, job
FROM employee
WHERE department_id = 1
UNION ALL
SELECT name, job
FROM employee
WHERE department_id = 4;
```

最终结果中的第一个字段名是第一条查询设置的`employee_name`。

## 4. 去重示例

下面两次查询中可能出现相同岗位，`UNION`会删除完全重复的结果：

```sql
SELECT job
FROM employee
WHERE department_id = 1
UNION
SELECT job
FROM employee
WHERE salary >= 10000;
```

如果改成`UNION ALL`，相同岗位会按照原来的出现次数全部保留。

## 5. 排序

需要对整个联合结果排序时，将`ORDER BY`写在最后一条查询之后：

```sql
SELECT name, salary
FROM employee
WHERE department_id = 1
UNION ALL
SELECT name, salary
FROM employee
WHERE department_id = 4
ORDER BY salary DESC;
```

# 多表查询概述

多表查询是从两张或多张数据表中查询数据，并根据表之间的关联条件组合查询结果。

## 1. 笛卡尔积

笛卡尔积是两个集合中所有元素的组合结果。

例如，集合A有2个元素，集合B有4个元素，得到的笛卡尔积共有：

```text
2 × 4 = 8种组合
```

同样，如果一张表有`m`条记录，另一张表有`n`条记录，两张表直接组合就会产生`m × n`条结果。

在普通多表查询中，如果没有正确设置表之间的关联条件，就会把互不相关的记录也组合起来，产生大量无效结果。这种现象通常称为产生了无效的笛卡尔积。

例如，员工表与部门表的有效关联条件是：

```text
employee.department_id = department.id
```

使用这个条件，可以只保留员工与其所属部门之间的有效组合。

笛卡尔积本身不是错误；需要获取所有组合时可以主动使用。普通关联查询通常需要通过关联条件排除无效组合。

## 2. 多表查询分类

多表查询主要分为连接查询和子查询。

### 2.1 连接查询

连接查询按照表之间的关联条件，把多张表中的记录组合成查询结果。

| 类型 | 作用 |
| --- | --- |
| [[内连接]] | 查询两张表中满足关联条件的数据，可以理解为查询两张表的交集部分 |
| [[外连接]] | 左外连接保留左表全部数据，右外连接保留右表全部数据 |
| 自连接 | 将一张表与它自身进行连接，必须为同一张表设置不同别名 |

左外连接和右外连接都属于外连接。

### 2.2 子查询

子查询是嵌套在另一条SQL语句中的查询。一条查询的结果可以作为另一条查询的条件、数据来源或临时结果。

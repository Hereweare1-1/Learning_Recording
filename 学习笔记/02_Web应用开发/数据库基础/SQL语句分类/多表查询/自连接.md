# 自连接

自连接是将一张表与它自身进行连接，用于查询同一张表中不同记录之间的关系。

自连接不是新的SQL关键字。它仍然使用`JOIN`、`LEFT JOIN`等连接语法，只是连接的两侧写的是同一张表。

## 1. 基本语法

```text
SELECT 字段列表
FROM 表名 别名1
JOIN 表名 别名2 ON 关联条件;
```

同一张表在查询中承担两个不同角色，因此必须设置不同的表别名，并通过别名区分字段来源。

设置别名不会复制数据，只是让同一张表在本次查询中拥有两个不同名称。

## 2. 员工与直属领导示例

假设员工表中包含以下字段：

```text
employee.id          员工编号
employee.name        员工姓名
employee.manager_id  直属领导的员工编号
```

`manager_id`引用的仍然是`employee`表中的`id`：

```text
employee.manager_id → employee.id
```

查询员工及其直属领导：

```sql
SELECT e.name AS employee_name,
       m.name AS manager_name
FROM employee AS e
INNER JOIN employee AS m
    ON e.manager_id = m.id;
```

这条查询中：

- `e`表示作为普通员工的记录。
- `m`表示作为直属领导的记录。
- `e.manager_id = m.id`表示员工的直属领导编号等于另一条员工记录的编号。

## 3. 自连接可以使用不同连接方式

自连接可以是内连接，也可以是外连接。

使用内连接时，没有直属领导的员工不会出现在结果中。要保留所有员工，可以使用左外连接：

```sql
SELECT e.name AS employee_name,
       m.name AS manager_name
FROM employee AS e
LEFT JOIN employee AS m
    ON e.manager_id = m.id;
```

如果某名员工没有直属领导，该员工仍然会显示，而`manager_name`为`NULL`。

## 4. 使用要点

- 自连接的两侧是同一张表，但代表不同的记录和角色。
- 必须使用不同别名，否则无法区分两侧字段。
- 自连接可以使用内连接、左外连接或其他连接方式。
- 选择哪种连接方式，取决于是否需要保留没有匹配记录的数据。

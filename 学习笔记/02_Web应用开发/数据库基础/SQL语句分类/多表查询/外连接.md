# 外连接

外连接不仅返回两张表中满足关联条件的记录，还会保留指定一侧没有匹配记录的数据。

## 1. 左外连接

左外连接返回左表的全部记录，以及右表中满足关联条件的记录。

```text
SELECT 字段列表
FROM 表1
LEFT [OUTER] JOIN 表2 ON 关联条件;
```

`OUTER`可以省略，`LEFT JOIN`与`LEFT OUTER JOIN`作用相同。`FROM`后面的表是左表，`JOIN`后面的表是右表。

例如，查询所有员工及其所属部门：

```sql
SELECT e.id,
       e.name,
       d.name AS department_name
FROM employee AS e
LEFT JOIN department AS d
    ON e.department_id = d.id;
```

即使某名员工没有匹配的部门，该员工也会出现在结果中，此时`department_name`为`NULL`。

## 2. 右外连接

右外连接返回右表的全部记录，以及左表中满足关联条件的记录。

```text
SELECT 字段列表
FROM 表1
RIGHT [OUTER] JOIN 表2 ON 关联条件;
```

`OUTER`同样可以省略，`RIGHT JOIN`与`RIGHT OUTER JOIN`作用相同。

例如，查询所有部门以及各部门中的员工：

```sql
SELECT d.id AS department_id,
       d.name AS department_name,
       e.name AS employee_name
FROM employee AS e
RIGHT JOIN department AS d
    ON e.department_id = d.id;
```

即使某个部门没有员工，该部门也会出现在结果中，此时`employee_name`为`NULL`。

## 3. 左外连接与右外连接的转换

交换两张表的位置，就可以使用左外连接表达原来的右外连接。下面的查询同样会保留全部部门：

```sql
SELECT d.id AS department_id,
       d.name AS department_name,
       e.name AS employee_name
FROM department AS d
LEFT JOIN employee AS e
    ON e.department_id = d.id;
```

实际书写时通常优先使用左外连接，把需要完整保留数据的表放在左侧，阅读起来更直观。

## 4. 使用要点

- 左连接保留左表全部数据，右连接保留右表全部数据。
- 没有匹配记录时，被保留表的数据正常显示，另一张表的字段显示为`NULL`。
- `ON`决定两张表如何匹配，遗漏或写错关联条件可能产生错误结果。
- 如果在`WHERE`中直接要求另一张表的字段必须满足条件，可能会过滤掉原本通过外连接保留的`NULL`记录。

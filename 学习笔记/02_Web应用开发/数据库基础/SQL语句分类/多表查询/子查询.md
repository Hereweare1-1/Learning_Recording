# 子查询

子查询是在一条SQL语句中嵌套另一条`SELECT`语句，也称为嵌套查询。子查询的结果会交给外层语句继续使用。

```text
外层SQL语句 (
    SELECT ...
);
```

子查询通常写在圆括号中。外层语句可以是`SELECT`、`INSERT`、`UPDATE`或`DELETE`。

## 1. 基本示例

查询工资高于全体员工平均工资的员工：

```sql
SELECT id, name, salary
FROM employee
WHERE salary > (
    SELECT AVG(salary)
    FROM employee
);
```

圆括号中的查询先得到平均工资，外层查询再使用这个结果筛选员工。

## 2. 按查询结果分类

子查询可以根据返回结果的形状分为四类：

| 类型 | 返回结果 |
| --- | --- |
| 标量子查询 | 一行一列，也就是一个值 |
| 列子查询 | 多行一列，也就是一列数据 |
| 行子查询 | 一行多列，也就是一条记录 |
| 表子查询 | 多行多列，可以看成一张临时结果表 |

外层语句使用子查询时，需要选择能够处理对应结果形状的写法。例如，普通比较运算符通常需要一个值，`IN`可以接收一列值，`FROM`可以接收表形式的结果。

## 3. 按书写位置分类

### 3.1 WHERE后的子查询

子查询结果可以作为`WHERE`中的筛选条件。上面的平均工资查询就是位于`WHERE`后的标量子查询。

列子查询可以配合`IN`使用。例如，查询研发部和销售部中的员工：

```sql
SELECT id, name, department_id
FROM employee
WHERE department_id IN (
    SELECT id
    FROM department
    WHERE name IN ('研发部', '销售部')
);
```

### 3.2 FROM后的子查询

子查询结果可以作为外层查询的数据来源。MySQL要求为`FROM`后的子查询设置别名。

```sql
SELECT grouped_job.job,
       grouped_job.average_salary
FROM (
    SELECT job,
           AVG(salary) AS average_salary
    FROM employee
    GROUP BY job
) AS grouped_job;
```

这里的子查询返回多行多列，属于表子查询。

### 3.3 SELECT后的子查询

子查询结果可以作为查询结果中的一个字段，此时通常需要返回单个值。

```sql
SELECT name,
       salary,
       (
           SELECT AVG(salary)
           FROM employee
       ) AS average_salary
FROM employee;
```

## 4. 使用要点

- 子查询需要使用圆括号包围。
- 子查询内部不要单独写分号，分号用于结束最外层的完整SQL语句。
- 外层语句的使用方式必须与子查询返回的行数和列数相匹配。
- 需要单个值的位置，如果子查询返回多行，SQL可能报错。
- `FROM`后的子查询需要设置别名。

# 子查询

子查询是在一条SQL语句中嵌套另一条`SELECT`语句，也称为嵌套查询。子查询的结果会交给外层语句继续使用。

```text
外层SQL语句 (
    SELECT ...
);
```

子查询通常写在圆括号中。外层语句可以是`SELECT`、`INSERT`、`UPDATE`或`DELETE`。

## 1. 基本示例

查询工资高于全体员工平均工资的员工：

```sql
SELECT id, name, salary
FROM employee
WHERE salary > (
    SELECT AVG(salary)
    FROM employee
);
```

圆括号中的查询先得到平均工资，外层查询再使用这个结果筛选员工。

## 2. 按查询结果分类

子查询可以根据返回结果的形状分为四类：

| 类型 | 返回结果 |
| --- | --- |
| 标量子查询 | 一行一列，也就是一个值 |
| 列子查询 | 多行一列，也就是一列数据 |
| 行子查询 | 一行多列，也就是一条记录 |
| 表子查询 | 多行多列，可以看成一张临时结果表 |

外层语句使用子查询时，需要选择能够处理对应结果形状的写法。例如，普通比较运算符通常需要一个值，`IN`可以接收一列值，`FROM`可以接收表形式的结果。

### 2.1 标量子查询

标量子查询只返回一个值，这个值可以是数字、字符串或日期等。它是一行一列的查询结果，也是最简单的子查询形式。

标量子查询可以配合普通比较运算符使用：

```text
=  <>  >  >=  <  <=
```

第1节中查询平均工资的子查询只返回一个数值，因此属于标量子查询。下面的子查询只返回研发部的部门编号：

```sql
SELECT id, name, department_id
FROM employee
WHERE department_id = (
    SELECT id
    FROM department
    WHERE name = '研发部'
);
```

这里使用`=`进行比较，因此圆括号中的子查询必须最多返回一个值。如果返回多行，外层语句无法判断应该与哪个值比较，MySQL会报错。

### 2.2 列子查询

列子查询返回一列数据，这一列可以包含多行。外层语句需要使用能够处理多个值的运算符。

| 运算符 | 作用 |
| --- | --- |
| `IN` | 外层值等于子查询结果中的任意一个值 |
| `NOT IN` | 外层值不等于子查询结果中的任何值 |
| `ANY` | 与比较运算符配合，只要满足子查询结果中的任意一个值即可 |
| `SOME` | 与`ANY`作用相同，可以互换 |
| `ALL` | 与比较运算符配合，必须满足子查询结果中的所有值 |

`ANY`、`SOME`和`ALL`通常写在比较运算符后面：

```text
字段 比较运算符 ANY  (列子查询)
字段 比较运算符 SOME (列子查询)
字段 比较运算符 ALL  (列子查询)
```

查询工资高于研发部任意一名员工工资的员工：

```sql
SELECT id, name, salary
FROM employee
WHERE salary > ANY (
    SELECT salary
    FROM employee
    WHERE department_id = 1
);
```

查询工资高于研发部所有员工工资的员工：

```sql
SELECT id, name, salary
FROM employee
WHERE salary > ALL (
    SELECT salary
    FROM employee
    WHERE department_id = 1
);
```

使用`NOT IN`时需要注意：如果子查询结果中包含`NULL`，比较结果可能无法确定，导致查询不到预期数据。可以先在子查询中使用`IS NOT NULL`排除空值。

### 2.3 行子查询

行子查询返回一行数据，这一行可以包含多个字段。外层语句可以把多个字段组成一个整体，与子查询返回的一行进行比较。

常用运算符包括：

```text
=  <>  IN  NOT IN
```

查询年龄和工资都与员工`E00003`相同的员工：

```sql
SELECT id, employee_no, name, age, salary
FROM employee
WHERE (age, salary) = (
    SELECT age, salary
    FROM employee
    WHERE employee_no = 'E00003'
);
```

`(age, salary)`按照字段位置与子查询返回的`age`和`salary`对应，因此两侧的字段数量、顺序和数据类型需要相互匹配。

使用`=`或`<>`时，子查询必须最多返回一行；如果返回多行，MySQL会报错。

`IN`和`NOT IN`也可以用于多字段整体比较，并允许子查询返回多行：

```sql
SELECT id, name, department_id, job
FROM employee
WHERE (department_id, job) IN (
    SELECT department_id, job
    FROM employee
    WHERE name IN ('张伟', '周静')
);
```

当子查询返回多行多列时，从结果形状上看也属于表子查询。

## 3. 按书写位置分类

### 3.1 WHERE后的子查询

子查询结果可以作为`WHERE`中的筛选条件。上面的平均工资查询就是位于`WHERE`后的标量子查询。

列子查询可以配合`IN`使用。例如，查询研发部和销售部中的员工：

```sql
SELECT id, name, department_id
FROM employee
WHERE department_id IN (
    SELECT id
    FROM department
    WHERE name IN ('研发部', '销售部')
);
```

### 3.2 FROM后的子查询

子查询结果可以作为外层查询的数据来源。MySQL要求为`FROM`后的子查询设置别名。

```sql
SELECT grouped_job.job,
       grouped_job.average_salary
FROM (
    SELECT job,
           AVG(salary) AS average_salary
    FROM employee
    GROUP BY job
) AS grouped_job;
```

这里的子查询返回多行多列，属于表子查询。

### 3.3 SELECT后的子查询

子查询结果可以作为查询结果中的一个字段，此时通常需要返回单个值。

```sql
SELECT name,
       salary,
       (
           SELECT AVG(salary)
           FROM employee
       ) AS average_salary
FROM employee;
```

## 4. 使用要点

- 子查询需要使用圆括号包围。
- 子查询内部不要单独写分号，分号用于结束最外层的完整SQL语句。
- 外层语句的使用方式必须与子查询返回的行数和列数相匹配。
- 需要单个值的位置，如果子查询返回多行，SQL可能报错。
- `FROM`后的子查询需要设置别名。

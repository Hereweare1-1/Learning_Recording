# MySQL数值函数

数值函数用于对数字进行取整、求余、生成随机数和四舍五入等计算。

## 1. 函数汇总

| 函数 | 作用 |
| --- | --- |
| `CEIL(x)` | 向上取整，返回不小于`x`的最小整数 |
| `FLOOR(x)` | 向下取整，返回不大于`x`的最大整数 |
| `MOD(x, y)` | 返回`x`除以`y`的余数 |
| `RAND()` | 返回大于或等于`0`且小于`1`的随机数 |
| `ROUND(x, y)` | 对`x`四舍五入，保留`y`位小数 |

通用调用形式为：

```text
SELECT 函数(参数);
```

## 2. CEIL和FLOOR：取整

`CEIL()`向数值更大的方向取整，`FLOOR()`向数值更小的方向取整：

```sql
SELECT CEIL(1.2), FLOOR(1.8);
```

结果分别为`2`和`1`。

负数同样遵循向上和向下的方向：

```sql
SELECT CEIL(-1.2), FLOOR(-1.2);
```

结果分别为`-1`和`-2`。

## 3. MOD：求余数

```sql
SELECT MOD(10, 3);
```

结果为`1`，因为`10`除以`3`后的余数是`1`。

## 4. RAND：生成随机数

```sql
SELECT RAND();
```

`RAND()`每次调用通常会返回一个不同的小数，取值范围是：

```text
0 <= 随机数 < 1
```

生成`1`到`100`之间的随机整数：

```sql
SELECT FLOOR(RAND() * 100) + 1;
```

## 5. ROUND：四舍五入

```text
ROUND(x, y)
```

- `x`：需要处理的数值。
- `y`：保留的小数位数。

例如，将圆周率保留两位小数：

```sql
SELECT ROUND(3.14159, 2);
```

结果为`3.14`。

省略第二个参数时，默认保留`0`位小数：

```sql
SELECT ROUND(3.6);
```

结果为`4`。

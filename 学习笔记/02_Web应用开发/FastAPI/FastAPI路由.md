# FastAPI路由

## 1. 什么是路由

**路由**用于规定：收到某种请求时，应该交给哪个函数处理。

```python
@app.get("/")
def root():
    return {"message": "Hello World"}
```

| 代码 | 含义 |
| --- | --- |
| `app` | 前面创建的FastAPI实例 |
| `get` | 接收HTTP的`GET`请求 |
| `"/"` | 请求路径，表示网站根路径 |
| `@app.get("/")` | 路径操作装饰器，把下面的函数登记为该路由的处理函数 |
| `root()` | 路径操作函数，请求匹配时由FastAPI调用 |
| `return {...}` | 返回响应数据，Python字典会被转换为JSON响应 |

## 2. 请求的执行过程

```text
客户端发送GET /
       ↓
FastAPI匹配@app.get("/")
       ↓
调用root()函数
       ↓
把返回值转换为HTTP响应
```

路径操作函数既可以使用普通的`def`，也可以使用`async def`。异步写法已经整理在[[Python Web框架对比#2. 异步支持应该怎样理解|异步支持应该怎样理解]]中，不在这里重复。

`@app.get()`使用了Python装饰器语法，装饰器基础可以查看[[闭包与装饰器#六、FastAPI中的装饰器]]。

# 大模型调用

## 网络基础知识

### 1. IP、域名、端口的作用

- **IP**：唯一定位一台网络设备
    
    - `127.0.0.1`：本机地址
        
- **域名**：方便记忆 IP 地址
    
    - `localhost`：本机域名
        
- **端口**：区分同一台设备上的不同程序
    
    - 范围：`0~65535`
        
    - 例如：`127.0.0.1:8000` → 本机的 8000 端口
        

### 2. 客户端和服务器

- **客户端**：主动发起请求的一方，例如 Python 程序、Vue 前端
    
- **服务器**：接收请求并提供服务的一方
    
- 基本过程：
    

```text
客户端 → 发送请求 → 服务器
客户端 ← 返回数据 ← 服务器
```

### 3. HTTP

**HTTP 是客户端和服务器之间进行通信的一套规则（协议）。**

常见用途：

```text
Python程序 → HTTP请求 → API服务器
Python程序 ← HTTP响应 ← API服务器
```

常见 HTTP 请求方法：

- **GET**：获取数据
    
- **POST**：提交数据 / 请求服务器执行操作
    
- **PUT**：修改数据
    
- **DELETE**：删除数据
    

大模型 API 调用中最常见的是 **POST**。

### 4. URL

**URL 就是资源的地址，用来告诉程序“请求哪个地方”。**

例如：

```text
https://api.example.com/chat
```

可以简单理解为：

```text
https://       → 使用 HTTPS 协议
api.example.com → 服务器地址
/chat          → 请求的接口路径
```

### 5. HTTP 请求

一个 HTTP 请求通常包含：

- **URL**：请求哪个地址
    
- **请求方法**：GET / POST 等
    
- **Headers（请求头）**：额外信息，例如身份认证
    
- **Body（请求体）**：真正要发送的数据
    

例如调用大模型：

```text
POST
↓
URL：大模型 API 地址
↓
Headers：API Key、Content-Type 等
↓
Body：模型、用户问题、参数等 JSON 数据
```

### 6. HTTP 响应

服务器处理请求后，会返回一个**响应**。

通常包括：

- **状态码**：表示请求是否成功
    
- **响应数据**：服务器返回的具体内容
    

常见状态码：

- `200`：请求成功
    
- `400`：请求参数有问题
    
- `401`：没有通过身份认证
    
- `403`：没有权限
    
- `404`：请求地址不存在
    
- `500`：服务器内部错误
    

### 7. JSON

**JSON 是一种用于程序之间传递结构化数据的数据格式。**

它长得和 Python 的字典、列表很像：

```json
{
    "name": "张三",
    "age": 20,
    "hobbies": ["音乐", "游戏"]
}
```

注意：

> JSON ≠ Python 字典  
> JSON 是数据格式，Python 解析 JSON 后通常会得到 `dict`、`list` 等对象。

API 经常使用 JSON，是因为它：

- 结构清晰
    
- 跨语言
    
- 容易解析
    

### 8. API

**API（应用程序接口）就是程序之间进行交互的一套接口和规则。**

例如：

```text
你的 Python 程序
      ↓
调用大模型 API
      ↓
大模型服务器
      ↓
返回结果
```

API 可以理解成：

> **程序访问另一个程序提供的功能的入口。**

### 9. 大模型 API 调用完整流程

```text
Python程序
   ↓
准备请求数据
   ↓
HTTP POST请求
   ↓
大模型 API
   ↓
服务器处理
   ↓
返回 HTTP 响应
   ↓
JSON 数据
   ↓
Python 解析数据
   ↓
得到 AI 回复
```

### 10. 一句话理解

> **HTTP 是通信规则，URL 是地址，IP 是设备地址，端口是程序入口，API 是服务提供的接口，JSON 是传递结构化数据的格式。**

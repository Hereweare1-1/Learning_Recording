# 对象复制（浅拷贝与深拷贝）

## 1. 为什么需要拷贝

深浅拷贝主要解决一个问题：复制列表、字典等可变对象后，修改新对象会不会影响原对象。

常见方式有三种：

1. 直接赋值。
2. 浅拷贝。
3. 深拷贝。

## 2. 三种方式先看结论

| 方式 | 常用写法 | 新的外层对象 | 内部可变对象是否共享 |
| --- | --- | --- | --- |
| 直接赋值 | `new = original` | 否 | 是 |
| 浅拷贝 | `new = original.copy()`或`copy.copy(original)` | 是 | 可能共享 |
| 深拷贝 | `new = copy.deepcopy(original)` | 是 | 通常不共享 |

- 浅拷贝创建新的外层对象，但把原对象内部元素的引用放入新对象中。
- 深拷贝创建新的外层对象，并继续递归复制内部对象。
- 浅拷贝开销较小，深拷贝的独立性更强，但开销也更大。

> [!note] 怎样选择
> 不能简单地认为“深拷贝用得多、浅拷贝用得少”。应该根据数据结构以及新旧数据是否需要完全独立来选择。

## 3. 对象身份：`id()`、`is`和`==`

变量保存对象时，可以把它理解为“变量名指向对象”。`id()`用于查看对象的身份标识，`is`用于判断两个变量是否指向同一个对象。

```python
list1 = [10, 20]
list2 = list1

print(id(list1))
print(id(list2))
print(list1 is list2)  # True
```

需要区分`==`和`is`：

```python
list1 = [10, 20]
list2 = [10, 20]

print(list1 == list2)  # True，内容相同
print(list1 is list2)  # False，不是同一个对象
```

| 写法 | 作用 |
| --- | --- |
| `a == b` | 比较两个对象的内容是否相同 |
| `a is b` | 比较是否为同一个对象 |
| `id(a)` | 查看对象的身份标识 |

> [!note] 注意
> `id()`返回的数字在每次运行程序时都可能不同，不要把它当成固定值。

## 4. 外层对象与内层对象

“外层”和“内层”指嵌套数据结构中的不同层级：

```python
list1 = [
    [10, 20],
    [30, 40]
]
```

- 最外面的大列表是**外层列表**。
- `[10, 20]`和`[30, 40]`是**内层列表**。
- 可以把它想成“一个大箱子里放着两个小箱子”。

修改外层：

```python
list1.append([50, 60])
```

修改内层：

```python
list1[0].append(100)
```

理解内外层，是区分浅拷贝和深拷贝的关键。

## 5. 直接赋值

直接赋值**不会创建新对象**，只是让两个变量指向同一个对象。

```python
list1 = [10, 20, 30]
list2 = list1

list2.append(40)

print(list1)           # [10, 20, 30, 40]
print(list2)           # [10, 20, 30, 40]
print(list1 is list2)  # True
```

通过任何一个变量修改列表，另一个变量看到的内容也会改变。

## 6. 浅拷贝

浅拷贝会创建一个新的**外层对象**，但内部的可变对象仍然可能与原对象共享。

列表可以使用`copy()`方法，也可以使用`copy`模块：

```python
import copy

list2 = list1.copy()
list3 = copy.copy(list1)
```

### 6.1 一维列表

```python
list1 = [10, 20, 30]
list2 = list1.copy()

list2.append(40)

print(list1)           # [10, 20, 30]
print(list2)           # [10, 20, 30, 40]
print(list1 is list2)  # False
```

对于只包含数字、字符串等不可变对象的一维列表，浅拷贝通常已经足够。

### 6.2 嵌套列表

```python
list1 = [[10, 20], [30, 40]]
list2 = list1.copy()

print(list1 is list2)        # False，外层不是同一个对象
print(list1[0] is list2[0])  # True，第一个内层列表仍然共享

list2[0].append(100)

print(list1)  # [[10, 20, 100], [30, 40]]
print(list2)  # [[10, 20, 100], [30, 40]]
```

> [!summary] 浅拷贝
> 外层对象不共享，但内部的可变对象仍然可能共享。

## 7. 深拷贝

深拷贝不仅创建新的外层对象，还会继续复制内部的可变对象。需要使用`copy`模块中的`deepcopy()`：

```python
import copy

list1 = [[10, 20], [30, 40]]
list2 = copy.deepcopy(list1)

list2[0].append(100)

print(list1)  # [[10, 20], [30, 40]]
print(list2)  # [[10, 20, 100], [30, 40]]

print(list1 is list2)        # False
print(list1[0] is list2[0])  # False
```

> [!summary] 深拷贝
> 外层对象和内部的可变对象都会被复制，新对象与原对象基本相互独立。

## 8. 字典的深浅拷贝

字典和列表的规则相同。如果字典内部包含列表、字典等可变对象，浅拷贝后这些内部对象仍然可能共享。

```python
import copy

student1 = {
    "name": "小明",
    "scores": [90, 80]
}

student2 = student1.copy()          # 浅拷贝
student3 = copy.deepcopy(student1)  # 深拷贝

student2["scores"].append(100)

print(student1["scores"])  # [90, 80, 100]，受到浅拷贝影响
print(student2["scores"])  # [90, 80, 100]
print(student3["scores"])  # [90, 80]，深拷贝不受影响
```

## 9. 什么时候使用

### 9.1 使用浅拷贝

数据结构比较简单，或者内部主要是数字、字符串等不可变对象时，可以使用浅拷贝：

```python
names = ["小明", "小红", "小刚"]
new_names = names.copy()
```

### 9.2 使用深拷贝

对象中存在多层列表、字典等可变对象，并且希望新旧数据互不影响时，可以使用深拷贝：

```python
import copy

users = [
    {"name": "小明", "hobbies": ["音乐", "游戏"]}
]

new_users = copy.deepcopy(users)
```

深拷贝并不是越多越好。如果数据中有本来就希望共享的对象，或者数据量很大，深拷贝可能会复制过多内容并增加开销。

### 9.3 不可变对象通常不需要拷贝

数字、字符串等不可变对象不能被原地修改，因此通常不需要进行浅拷贝或深拷贝。重新赋值只会让变量指向另一个对象，不会修改原来的值。

元组本身虽然不可变，但元组内部仍然可以包含列表等可变对象。遇到这种复合结构时，仍然需要判断内部对象是否会被共享。

## 10. 最终总结

1. 直接赋值不会复制对象，只是增加一个指向同一对象的变量名。
2. 浅拷贝可以使用`copy.copy()`；列表、字典和集合等容器也可以使用自身的`copy()`方法。
3. 深拷贝使用`copy.deepcopy()`，它会递归处理内部对象。
4. 浅拷贝只新建外层容器，内部可变对象仍可能共享；深拷贝会继续复制内层对象，使新旧数据尽量相互独立。
5. 对数字、字符串等不可变对象，浅拷贝和深拷贝通常没有实际必要。

> [!tip] 最简单的记忆方法
> 赋值只增加变量名；浅拷贝只新建外层容器；深拷贝继续递归复制内层对象。

# Python 面向对象高级

## 面向对象三大特性之间的关系

- **封装**：将属性和方法写在类的内部，仅对外提供公共方法，不暴露具体细节。
  - 好处：提升安全性。
  - 坏处：代码量增加，例如需要为私有属性额外提供访问方法。
    - 解决思路 → **继承**：让子类直接拥有父类已有的属性和方法，减少重复代码。
      - 好处：减少代码量，提高代码复用性。
      - 坏处：子类依赖父类，增加了代码的耦合性。
        - 进一步扩展 → **多态**：同一个调用在传入不同的子类对象时，会产生不同的执行结果。

> [!summary] 三者关系
> 先用**封装**组成类，再用**继承**复用类，最后通过子类重写方法实现**多态**。

## Python 封装

### 1. 什么是封装

封装是将数据（属性）与操作数据的方法绑定在一起，形成一个独立的类。

### 2. 私有属性、私有方法与公共成员的区别

- 私有属性和私有方法只能在类的内部访问，外部不能直接访问。
- 公共属性和公共方法在类的内部和外部都可以访问。
- 私有属性和私有方法通常以双下划线`__`开头。
- Python没有绝对的私有机制，双下划线主要通过名称改写限制外部访问。

```python
class Student:
    def __init__(self, name):
        self.name = name          # 公共属性
        self.__score = 90         # 私有属性

    def show_name(self):          # 公共方法
        print(self.name)

    def __show_score(self):       # 私有方法
        print(self.__score)
```

### 3. 私有属性和私有方法的应用场景

如果某些属性和方法不希望直接向使用者公开，可以将其设置为私有成员，以保护内部数据和实现细节。

## Python 继承

### 1. 继承的语法

```python
class 子类(父类):
    pass
```

示例：

```python
class Animal:
    def eat(self):
        print("正在吃东西")


class Dog(Animal):
    pass


dog = Dog()
dog.eat()
```

### 2. 子类可以继承哪些成员

子类可以继承父类的属性和方法。

- 公共成员：子类可以直接访问。
- 以双下划线`__`开头的私有成员：也会被继承，但由于名称改写，子类不能直接访问。

```python
class Parent:
    def __init__(self):
        self.name = "父类"
        self.__age = 40


class Child(Parent):
    def show(self):
        print(self.name)      # 可以访问
        # print(self.__age)   # 不能直接访问
```

因此，严格来说不能简单地说“私有成员不会被继承”，而是“会继承，但子类不能直接访问”。

## 方法重写

### 1. 什么是方法重写

在继承体系中，如果父类的方法不能满足需求，就可以在子类中重新定义一个与父类同名的方法，用子类自己的实现替换父类的实现，这称为方法重写。

### 2. 方法重写的语法

```python
class 父类:
    def 方法名(self):
        pass


class 子类(父类):
    def 方法名(self):
        pass
```

### 3. 在子类中调用父类的方法

方式一：

```python
super().方法名()
```

方式二：

```python
父类名.方法名(self)
```

## 多继承

### 1. 什么是多继承

多继承是指一个子类同时继承多个父类。子类会继承多个父类中的非私有属性和方法。

### 2. 多继承的语法

```python
class 子类名(父类1, 父类2, 父类3, ...):
    代码
```

### 3. 多继承的调用顺序

当多个父类中存在同名属性或方法时，Python会按照MRO（方法解析顺序）查找，通常优先使用写在前面的父类中的同名成员。

```python
class Son(Father1, Father2):
    pass
```

此时会优先查找`Father1`，然后再查找`Father2`。

可以使用以下方式查看调用顺序：

```python
类名.__mro__
```

或：

```python
类名.mro()
```

### 4. 调用指定父类的方法和属性

如果想调用后面父类中的同名方法，可以在子类中重写该方法，再通过`父类名.方法名(self)`指定调用：

```python
class Father1:
    def show(self):
        print("父类1")


class Father2:
    def show(self):
        print("父类2")


class Son(Father1, Father2):
    def show(self):
        Father2.show(self)
```

如果是类属性，可以通过`父类名.属性名`访问：

```python
class Father2:
    name = "父类2"


class Son:
    def show(self):
        print(Father2.name)
```

如果是父类在`__init__()`中创建的实例属性，需要先调用对应父类的`__init__()`，不能简单地使用`父类名.属性名`访问。

## 多态

### 1. 什么是多态

多态是指：调用同一个方法时，因为传入的对象不同，最终产生不同的执行结果。

定义函数时，将参数类型指定为父类；调用函数时，可以传入不同的子类对象，从而执行各个子类重写后的方法。

### 2. 实现多态的三个条件

1. **有继承**：定义父类和子类，子类继承父类。
2. **有方法重写**：子类重新实现父类中的同名方法。图片中的“函数重写”，在Python面向对象中通常叫“方法重写”。
3. **父类类型接收子类对象**：将子类对象传给父类类型的变量或形参，再调用同名方法。

```python
class Animal:
    def speak(self):
        print("动物正在叫")


class Dog(Animal):                 # 条件1：Dog继承Animal
    def speak(self):               # 条件2：重写父类的speak方法
        print("小狗：汪汪汪")


class Cat(Animal):                 # 条件1：Cat继承Animal
    def speak(self):               # 条件2：重写父类的speak方法
        print("小猫：喵喵喵")


def make_sound(animal: Animal):    # 条件3：父类类型的形参接收子类对象
    animal.speak()


make_sound(Dog())  # 小狗：汪汪汪
make_sound(Cat())  # 小猫：喵喵喵
```

`make_sound()`调用的始终是同一个`speak()`方法，但传入`Dog`和`Cat`对象时结果不同，这就是多态。

> [!note] Python中的理解
> Python是动态类型语言。“父类引用指向子类对象”在Python中通常表现为：用父类类型的形参接收不同的子类对象。

### 3. `XX: XX`写法是什么意思

```python
animal: Animal
```

这是Python的类型注解，表示参数`animal`预期接收`Animal`类型的对象。

```python
def make_sound(animal: Animal):
    animal.speak()
```

其中：

- 前面的`animal`是参数名。
- 冒号后面的`Animal`是参数的类型。
- 因为`Dog`和`Cat`都是`Animal`的子类，所以也可以传入。

类型注解主要用于说明参数类型和提供代码提示，Python运行时通常不会强制检查类型。

## 抽象类与抽象方法

### 1. 什么是抽象类

抽象类可以理解为给子类制定规则的“模板类”。它主要用于被其他类继承，一般不能直接创建对象。

它的作用是规定子类必须实现哪些方法，让不同的子类遵守统一的代码规范。

例如，猫和狗发出的声音不同，但是它们都必须具备“叫”这个行为。我们可以在父类中只规定它们必须有`speak()`方法，具体怎样叫则交给各个子类实现。

Python中的抽象类需要继承`abc`模块提供的`ABC`类：

```python
from abc import ABC, abstractmethod
```

- `ABC`是`Abstract Base Class`的缩写，意思是“抽象基类”。
- `abstractmethod`用于把一个方法标记为抽象方法。

### 2. 什么是抽象方法

抽象方法是在抽象类中**只规定方法名和基本形式，不提供具体功能**的方法。继承抽象类的子类必须重写这个方法，否则子类也不能创建对象。

在方法上方添加`@abstractmethod`，就可以把它标记为抽象方法：

```python
from abc import ABC, abstractmethod


class Animal(ABC):
    @abstractmethod  # 标记该方法必须由子类实现
    def speak(self):
        pass
```

此时，`Animal`中包含抽象方法，所以不能直接创建`Animal`对象：

```python
animal = Animal()  # 报错：抽象类不能直接实例化
```

### 3. 子类必须实现抽象方法

```python
from abc import ABC, abstractmethod


class Animal(ABC):
    @abstractmethod
    def speak(self):
        pass


class Dog(Animal):
    def speak(self):
        print("小狗：汪汪汪")


class Cat(Animal):
    def speak(self):
        print("小猫：喵喵喵")


dog = Dog()
cat = Cat()

dog.speak()  # 小狗：汪汪汪
cat.speak()  # 小猫：喵喵喵
```

如果子类没有实现`speak()`抽象方法，那么这个子类也不能创建对象：

```python
class Bird(Animal):
    pass


bird = Bird()  # 报错：Bird没有实现speak抽象方法
```

### 4. 抽象方法和多态的关系

- 抽象方法负责定规则：要求所有子类都必须具有相同的方法。
- 方法重写负责实现规则：每个子类用自己的方式完成这个方法。
- 多态负责统一调用：调用相同的方法时，不同的子类对象表现出不同的结果。

> [!tip] 一句话总结
> 抽象类规定“必须做什么”，子类决定“具体怎么做”。

## 鸭子类型

鸭子类型（Duck Typing）是指：如果一个对象走路像鸭子、叫起来像鸭子，那么就可以把它当作鸭子。

在鸭子类型中，关注的是对象的行为，也就是对象具有什么方法，而不是对象属于什么类。

```python
class Dog:
    def swimming(self):
        print(f"{self.age}岁的{self.name}正在游泳……")


class Duck:
    def swimming(self):
        print(f"{self.age}岁的{self.name}正在游泳……")


class Pig:
    def swimming(self):
        print(f"{self.age}岁的{self.name}正在游泳……")
```

定义函数：

```python
def go_swimming(duck):
    duck.swimming()
```

测试代码：

```python
if __name__ == "__main__":
    go_swimming(Dog("旺财", 4))
    go_swimming(Duck("唐老鸭", 2))
    go_swimming(Pig("佩奇", 1))
```

`Dog`、`Duck`和`Pig`之间不需要存在继承关系。只要传入的对象具有`swimming()`方法，就可以传给`go_swimming()`函数使用。

鸭子类型的优势是不需要存在继承关系，只要对象具有相应的方法就能使用。

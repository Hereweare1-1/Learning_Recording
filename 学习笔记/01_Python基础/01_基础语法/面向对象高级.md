# Python封装

## 1. 什么是封装

封装是将数据（属性）与操作数据的方法绑定在一起，形成一个独立的类。

## 2. 私有属性、私有方法与公共成员的区别

- 私有属性和私有方法只能在类的内部访问，外部不能直接访问。
- 公共属性和公共方法在类的内部和外部都可以访问。
- 私有属性和私有方法通常以双下划线`__`开头。
- Python没有绝对的私有机制，双下划线主要通过名称改写限制外部访问。

```
class Student:
    def __init__(self, name):
        self.name = name          # 公共属性
        self.__score = 90         # 私有属性

    def show_name(self):          # 公共方法
        print(self.name)

    def __show_score(self):       # 私有方法
        print(self.__score)
```

## 3. 私有属性和私有方法的应用场景

如果某些属性和方法不希望直接向使用者公开，可以将其设置为私有成员，以保护内部数据和实现细节。


# Python继承

## 1. 继承的语法

```
class 子类(父类):
    pass
```

示例：

```
class Animal:
    def eat(self):
        print("正在吃东西")


class Dog(Animal):
    pass


dog = Dog()
dog.eat()
```

## 2. 子类可以继承哪些成员

子类可以继承父类的属性和方法。

- 公共成员：子类可以直接访问。
- 以双下划线`__`开头的私有成员：也会被继承，但由于名称改写，子类不能直接访问。

```
class Parent:
    def __init__(self):
        self.name = "父类"
        self.__age = 40


class Child(Parent):
    def show(self):
        print(self.name)      # 可以访问
        # print(self.__age)   # 不能直接访问
```

因此，严格来说不能简单地说“私有成员不会被继承”，而是“会继承，但子类不能直接访问”。

# 方法重写

## 1. 什么是方法重写

在继承体系中，如果父类的方法不能满足需求，就可以在子类中重新定义一个与父类同名的方法，用子类自己的实现替换父类的实现，这称为方法重写。

## 2. 方法重写的语法

```
class 父类:
    def 方法名(self):
        pass


class 子类(父类):
    def 方法名(self):
        pass
```

## 3. 在子类中调用父类的方法

方式一：

```
super().方法名()
```

方式二：

```
父类名.方法名(self)
```

# 多继承

## 1. 什么是多继承

多继承是指一个子类同时继承多个父类。子类会继承多个父类中的非私有属性和方法。

## 2. 多继承的语法

```python
class 子类名(父类1, 父类2, 父类3, ...):
    代码
```

## 3. 多继承的调用顺序

当多个父类中存在同名属性或方法时，Python会按照MRO（方法解析顺序）查找，通常优先使用写在前面的父类中的同名成员。

```python
class Son(Father1, Father2):
    pass
```

此时会优先查找`Father1`，然后再查找`Father2`。

可以使用以下方式查看调用顺序：

```python
类名.__mro__
```

或：

```python
类名.mro()
```

## 4. 调用指定父类的方法和属性

如果想调用后面父类中的同名方法，可以在子类中重写该方法，再通过`父类名.方法名(self)`指定调用：

```python
class Father1:
    def show(self):
        print("父类1")


class Father2:
    def show(self):
        print("父类2")


class Son(Father1, Father2):
    def show(self):
        Father2.show(self)
```

如果是类属性，可以通过`父类名.属性名`访问：

```python
class Father2:
    name = "父类2"


class Son:
    def show(self):
        print(Father2.name)
```

如果是父类在`__init__()`中创建的实例属性，需要先调用对应父类的`__init__()`，不能简单地使用`父类名.属性名`访问。


# 多态

## 1. 什么是多态

多态是指同一个方法具有不同的表现形式。

定义函数时，将参数类型指定为父类；调用函数时，可以传入不同的子类对象，从而执行各个子类重写后的方法。

```
class Car:
    def charge(self):
        print("正在补充燃料……")


class FuelCar(Car):
    def charge(self):
        print("燃油汽车正在加油……")


class ElectricCar(Car):
    def charge(self):
        print("电动汽车正在充电……")
```

定义统一的调用函数：

```
def handle_charge(car: Car):
    car.charge()
```

调用时传入不同的子类对象：

```
handle_charge(FuelCar("BMW", "X5", "白色", 500, "张三"))
handle_charge(ElectricCar("BYD", "汉", "白色", 500, "张三"))
```

同一个`handle_charge()`函数，传入的对象不同，最终执行的`charge()`方法也不同。

## 2. `XX: XX`写法是什么意思

```
car: Car
```

这是Python的类型注解，表示参数`car`预期接收`Car`类型的对象。

```
def handle_charge(car: Car):
    car.charge()
```

其中：

- 前面的`car`是参数名。
- 冒号后面的`Car`是参数的类型。
- 因为`FuelCar`和`ElectricCar`都是`Car`的子类，所以也可以传入。

类型注解主要用于说明参数类型和提供代码提示，Python运行时通常不会强制检查类型。

# 鸭子类型

鸭子类型（Duck Typing）是指：如果一个对象走路像鸭子、叫起来像鸭子，那么就可以把它当作鸭子。

在鸭子类型中，关注的是对象的行为，也就是对象具有什么方法，而不是对象属于什么类。

```
class Dog:
    def swimming(self):
        print(f"{self.age}岁的{self.name}正在游泳……")


class Duck:
    def swimming(self):
        print(f"{self.age}岁的{self.name}正在游泳……")


class Pig:
    def swimming(self):
        print(f"{self.age}岁的{self.name}正在游泳……")
```

定义函数：

```
def go_swimming(duck):
    duck.swimming()
```

测试代码：

```
if __name__ == "__main__":
    go_swimming(Dog("旺财", 4))
    go_swimming(Duck("唐老鸭", 2))
    go_swimming(Pig("佩奇", 1))
```

`Dog`、`Duck`和`Pig`之间不需要存在继承关系。只要传入的对象具有`swimming()`方法，就可以传给`go_swimming()`函数使用。

鸭子类型的优势是不需要存在继承关系，只要对象具有相应的方法就能使用。

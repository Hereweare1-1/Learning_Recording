# 深浅拷贝

## 一、为什么需要拷贝

深浅拷贝主要解决一个问题：复制列表、字典等可变对象后，修改新对象会不会影响原对象。

常见方式有三种：

1. 直接赋值。
2. 浅拷贝。
3. 深拷贝。

## 二、对象身份：`id()`、`is`和`==`

变量保存对象时，可以把它理解为“变量名指向对象”。`id()`用于查看对象的身份标识，`is`用于判断两个变量是否指向同一个对象。

```python
list1 = [10, 20]
list2 = list1

print(id(list1))
print(id(list2))
print(list1 is list2)  # True
```

需要区分`==`和`is`：

```python
list1 = [10, 20]
list2 = [10, 20]

print(list1 == list2)  # True，内容相同
print(list1 is list2)  # False，不是同一个对象
```

| 写法 | 作用 |
| --- | --- |
| `a == b` | 比较两个对象的内容是否相同 |
| `a is b` | 比较是否为同一个对象 |
| `id(a)` | 查看对象的身份标识 |

> [!note] 注意
> `id()`返回的数字在每次运行程序时都可能不同，不要把它当成固定值。

## 三、外层对象与内层对象

“外层”和“内层”指嵌套数据结构中的不同层级：

```python
list1 = [
    [10, 20],
    [30, 40]
]
```

- 最外面的大列表是**外层列表**。
- `[10, 20]`和`[30, 40]`是**内层列表**。
- 可以把它想成“一个大箱子里放着两个小箱子”。

修改外层：

```python
list1.append([50, 60])
```

修改内层：

```python
list1[0].append(100)
```

理解内外层，是区分浅拷贝和深拷贝的关键。

## 四、直接赋值

直接赋值**不会创建新对象**，只是让两个变量指向同一个对象。

```python
list1 = [10, 20, 30]
list2 = list1

list2.append(40)

print(list1)           # [10, 20, 30, 40]
print(list2)           # [10, 20, 30, 40]
print(list1 is list2)  # True
```

通过任何一个变量修改列表，另一个变量看到的内容也会改变。

## 五、浅拷贝

浅拷贝会创建一个新的**外层对象**，但内部的可变对象仍然可能与原对象共享。

列表可以使用`copy()`方法，也可以使用`copy`模块：

```python
import copy

list2 = list1.copy()
list3 = copy.copy(list1)
```

### 1. 一维列表

```python
list1 = [10, 20, 30]
list2 = list1.copy()

list2.append(40)

print(list1)           # [10, 20, 30]
print(list2)           # [10, 20, 30, 40]
print(list1 is list2)  # False
```

对于只包含数字、字符串等不可变对象的一维列表，浅拷贝通常已经足够。

### 2. 嵌套列表

```python
list1 = [[10, 20], [30, 40]]
list2 = list1.copy()

print(list1 is list2)        # False，外层不是同一个对象
print(list1[0] is list2[0])  # True，第一个内层列表仍然共享

list2[0].append(100)

print(list1)  # [[10, 20, 100], [30, 40]]
print(list2)  # [[10, 20, 100], [30, 40]]
```

> [!summary] 浅拷贝
> 外层对象不共享，但内部的可变对象仍然可能共享。

## 六、深拷贝

深拷贝不仅创建新的外层对象，还会继续复制内部的可变对象。需要使用`copy`模块中的`deepcopy()`：

```python
import copy

list1 = [[10, 20], [30, 40]]
list2 = copy.deepcopy(list1)

list2[0].append(100)

print(list1)  # [[10, 20], [30, 40]]
print(list2)  # [[10, 20, 100], [30, 40]]

print(list1 is list2)        # False
print(list1[0] is list2[0])  # False
```

> [!summary] 深拷贝
> 外层对象和内部的可变对象都会被复制，新对象与原对象基本相互独立。

## 七、字典的深浅拷贝

字典和列表的规则相同。如果字典内部包含列表、字典等可变对象，浅拷贝后这些内部对象仍然可能共享。

```python
import copy

student1 = {
    "name": "小明",
    "scores": [90, 80]
}

student2 = student1.copy()          # 浅拷贝
student3 = copy.deepcopy(student1)  # 深拷贝

student2["scores"].append(100)

print(student1["scores"])  # [90, 80, 100]，受到浅拷贝影响
print(student2["scores"])  # [90, 80, 100]
print(student3["scores"])  # [90, 80]，深拷贝不受影响
```

## 八、三种方式对比

| 方式 | 写法 | 新的外层对象 | 内部可变对象是否共享 |
| --- | --- | --- | --- |
| 直接赋值 | `new = original` | 否 | 是 |
| 浅拷贝 | `new = original.copy()` | 是 | 可能共享 |
| 深拷贝 | `new = copy.deepcopy(original)` | 是 | 通常不共享 |

## 九、什么时候使用

### 使用浅拷贝

数据结构比较简单，或者内部主要是数字、字符串等不可变对象时，可以使用浅拷贝：

```python
names = ["小明", "小红", "小刚"]
new_names = names.copy()
```

### 使用深拷贝

对象中存在多层列表、字典等可变对象，并且希望新旧数据互不影响时，可以使用深拷贝：

```python
import copy

users = [
    {"name": "小明", "hobbies": ["音乐", "游戏"]}
]

new_users = copy.deepcopy(users)
```

> [!tip] 最简单的记忆方法
> 直接赋值没有复制；浅拷贝只复制外面的大箱子；深拷贝把里面的小箱子也一起复制。

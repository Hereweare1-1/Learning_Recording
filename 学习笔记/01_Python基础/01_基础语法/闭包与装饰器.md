# 闭包与装饰器

## 一、函数本身与函数调用

在 Python 中，函数也可以像普通数据一样：保存到变量中、作为参数传递，或者作为返回值返回。

```python
def hello():
    print("你好")


hello()  # 调用函数，执行函数中的代码
hello    # 表示函数本身，不会执行
```

函数本身还可以赋值给变量，或者传给另一个函数：

```python
def hello():
    print("你好")


def run(func):
    func()


a = hello
a()         # 输出：你好
run(hello)  # 把hello函数本身传给run
```

> [!important] 注意
> `run(hello)`传入的是函数本身；`run(hello())`会先执行`hello()`，再把它的返回值传给`run()`，两者含义不同。

## 二、闭包

### 1. 什么是闭包

闭包是指：**内部函数使用了外部函数中的变量，并且外部函数返回了这个内部函数。**

即使外部函数已经执行结束，返回的内部函数仍然能够记住并使用外部变量。

```python
def outer(name):
    def inner():
        print(f"你好，{name}")

    return inner


result = outer("小明")
result()  # 输出：你好，小明
```

执行过程：

1. 调用`outer("小明")`，`name`的值为`"小明"`。
2. `outer()`创建并返回`inner`函数。
3. `result`接收到`inner`函数。
4. 调用`result()`时，`inner()`仍然记得`name`的值。

### 2. 闭包的基本结构

```python
def 外部函数():
    外部变量 = 某个值

    def 内部函数():
        使用外部变量

    return 内部函数
```

### 3. 闭包的作用

闭包可以保存数据或状态，并根据不同的数据创建不同的函数。

```python
def create_multiplier(number):
    def multiply(value):
        return number * value

    return multiply


double = create_multiplier(2)
triple = create_multiplier(3)

print(double(10))  # 20，double记住了number = 2
print(triple(10))  # 30，triple记住了number = 3
```

## 三、`nonlocal`关键字

### 1. `nonlocal`的作用

内部函数可以直接读取外部函数的变量；如果要对这个变量重新赋值或累加，就需要使用`nonlocal`。

```python
def create_counter():
    count = 0

    def counter():
        nonlocal count
        count += 1
        print(count)

    return counter


my_counter = create_counter()
my_counter()  # 1
my_counter()  # 2
my_counter()  # 3
```

在这个例子中：

- 闭包负责记住`count`。
- `nonlocal`负责修改外层函数中的`count`。

如果删除`nonlocal`，Python会把`count`当作内部函数的局部变量。执行`count += 1`时，这个局部变量还没有值，因此会出现`UnboundLocalError`。

### 2. `nonlocal`与`global`的区别

| 关键字 | 操作的变量 |
| --- | --- |
| `nonlocal` | 外层函数中的局部变量 |
| `global` | 函数外部的全局变量 |

- `nonlocal`：向外查找其他函数中的变量。
- `global`：查找当前模块中的全局变量。

## 四、装饰器

### 1. 什么是装饰器

装饰器可以在**不修改原函数内部代码**的情况下，给原函数增加功能。

```python
def add_message(func):
    def wrapper():
        print("函数开始执行")
        func()
        print("函数执行结束")

    return wrapper


def study():
    print("正在学习")


study = add_message(study)
study()
```

输出：

```text
函数开始执行
正在学习
函数执行结束
```

这里的执行过程是：

1. 原来的`study`函数被传给`add_message()`。
2. `add_message()`返回`wrapper`函数。
3. `study`重新指向`wrapper`。
4. 调用新的`study()`时，实际执行的是`wrapper()`。
5. `wrapper()`在调用原函数前后增加了新功能。

### 2. `@`装饰器语法

下面两种写法完全等价：

```python
# 普通写法
def study():
    print("正在学习")


study = add_message(study)
```

```python
# 装饰器写法
@add_message
def study():
    print("正在学习")
```

因此，可以记住下面这个转换关系：

```python
@装饰器
def 原函数():
    pass

# 等价于：原函数 = 装饰器(原函数)
```

### 3. 通用装饰器

如果原函数有参数和返回值，可以用`*args`、`**kwargs`接收参数，并保存和返回原函数的结果：

```python
def logger(func):
    def wrapper(*args, **kwargs):
        print("函数开始执行")
        result = func(*args, **kwargs)
        print("函数执行结束")
        return result

    return wrapper


@logger
def add(a, b):
    return a + b


result = add(10, 20)
print(result)  # 30
```

- `*args`接收位置参数。
- `**kwargs`接收关键字参数。
- `result`保存原函数的返回值。
- `return result`把原函数的结果继续返回给调用者。

## 五、闭包与装饰器的关系

装饰器通常使用闭包实现：

```python
def logger(func):
    def wrapper():
        func()

    return wrapper
```

它符合闭包的三个常见特点：

1. `wrapper()`是内部函数。
2. `wrapper()`使用了外部函数中的`func`。
3. 外部函数返回了`wrapper`。

因此，`wrapper()`能够记住`func`，也就是记住原来的函数。

## 六、FastAPI中的装饰器

[[FastAPI路由|FastAPI]]中经常出现下面的写法：

```python
@app.get("/users")
def get_users():
    return {"users": []}
```

`@app.get("/users")`是装饰器。现阶段可以把它理解为：将`get_users()`登记为处理`GET /users`请求的函数。

## 七、核心总结

| 知识点        | 需要记住的内容                       |
| ---------- | ----------------------------- |
| 函数名        | `hello`表示函数本身，`hello()`表示调用函数 |
| 闭包         | 内部函数能够使用并记住外部函数中的数据           |
| `nonlocal` | 让内部函数可以修改外层函数中的局部变量           |
| 装饰器        | 在不修改原函数内部代码的情况下增加功能           |
| `@logger`  | 等价于`原函数 = logger(原函数)`        |

> [!summary] 一句话理解
> 闭包让内部函数“记住外部数据”，装饰器利用这个特点“记住原函数”，并在调用原函数前后增加功能。

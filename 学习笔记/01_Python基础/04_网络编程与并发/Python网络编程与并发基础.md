# Python网络编程与并发基础

这篇笔记先记录网络编程、进程和线程的大概框架。现阶段我只需要理解它们之间的关系，具体用法和代码等学到后再补充。

## 1. 整体关系

```text
Python网络编程
└─ Socket：让程序之间通过网络交换数据
   ├─ IP地址：找到目标设备
   ├─ 端口号：找到设备中对应的程序
   └─ 协议：规定双方交换数据的规则

Python并发与多任务
├─ 进程：操作系统分配和管理资源的基本单位
└─ 线程：操作系统调度执行的基本单位
   └─ 多个线程共享数据时，可能需要使用互斥锁
```

## 2. 网络编程与Socket

**网络编程**就是让不同程序之间通过网络交换数据。这些程序可以运行在不同计算机上，也可以运行在同一台计算机上。

进行网络通信时，我需要先理解：

- **IP地址**：用于找到网络中的目标设备。
- **端口号**：用于找到设备中负责通信的具体程序。
- **协议**：规定通信双方应该按照什么格式和规则交换数据。
- **Socket（套接字）**：程序进行网络通信时使用的工具和接口。

IP地址和端口号的基础内容见：[[Web网络基础#4. IP地址和端口号]]。

> [!note]
> Socket是网络编程的基础接口；WebSocket是一种具体的应用层通信协议，二者不是同一个概念。

## 3. 进程

**进程**可以先理解为一个正在运行的程序。例如，同时运行微信和QQ，就产生了不同的进程。

- 进程是操作系统分配和管理资源的基本单位。
- 不同进程的内存空间通常相互隔离，一个进程不能随意修改另一个进程的数据。
- Python中与多进程相关的模块是`multiprocessing`。

## 4. 线程

**线程**是进程中真正执行任务的单位。一个进程中可以包含一个或多个线程。

- 线程是操作系统调度执行的基本单位。
- 同一进程中的线程会共享该进程的部分数据和资源。
- 线程比进程更轻量，但共享数据时更容易发生冲突。
- Python中与多线程相关的模块是`threading`。

## 5. 进程和线程的简单对比

| 对比项 | 进程 | 线程 |
| --- | --- | --- |
| 基本作用 | 运行一个相对独立的程序或任务 | 在进程内部执行具体任务 |
| 数据关系 | 不同进程的数据通常相互隔离 | 同一进程中的线程可以共享数据 |
| 创建和切换 | 开销通常较大 | 开销通常较小 |
| 需要注意 | 进程间传递数据需要专门的通信方式 | 共享数据时需要避免相互干扰 |

## 6. 互斥锁

多个线程同时修改同一份数据时，可能出现数据混乱。

**互斥锁**可以理解为给共享数据加一把锁：同一时间只允许一个线程操作这部分数据，其他线程需要等待。具体的加锁方法和代码等学习线程时再补充。

    ↓

    ↓

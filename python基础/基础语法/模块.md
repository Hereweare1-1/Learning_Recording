### Python中的内置变量
- **__name__** ：每个文件都自带，不需要自己定义。
	- 当直接运行__name__所属文件时，它的值为__main__;
	- 当__name__所属文件被导入到其他文件运行时，它的值变为所属文件名。
	- **作用：** 便于给每个模块写测试代码，只有当直接运行这个模块时才会执行测试代码
```
if __name__ == "__main__":
	#测试代码
```

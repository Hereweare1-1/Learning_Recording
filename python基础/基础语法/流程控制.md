### 分支结构
##### if elif else
适用于复杂的条件判断
##### match case （相当于C里的switch case）
适用于某个变量有多个固定值
```
```
n1=float(input("请输入第一个数："))  
n2=float(input("请输入第二个数："))  
s=input("请输入操作符")  
match s:  
    case "+":  
        print(f"{n1} + {n2}={n1 + n2}")  
    case "-":  
        print(f"{n1} - {n2}={n1 - n2}")  
    case " * ":  
        print(f"{n1}* {n2}={n1 * n2}")  
    case "/ " if n2 != 0:  
        print(f"{n1}/ {n2}={n1 / n2}")  
    case _ :  
        print("输入有误")
```
```
提示：case _ 相当于default；且case "" 后可以跟条件判断语句
```
day = input("请输入星期几(1-7): ")  
match day:  
    case "1":        print("周一：工作会议日")  
    case "2":        print("周二：学习培训日")  
    case "3":        print("周三：项目开发日")  
    case "4":        print("周四：代码审查日")  
    case "5":        print("周五：总结规划日")  
    case "6" | "7":        print("周末：休息放松")  
    case _:        print("输入有误!!!")
```
提示："6" | "7"的意思是匹配6或者7
### 循环结构
**whlie循环**（未知循环次数，只知道循环结束条件时用）
后面也可以跟else，但只有当条件表达式为False退出循环时才会执行else中的语句；如果是因为异常或break退出循环则不会执行
**for循环**（已知循环次数或遍历数据集时用）
```
mess=input("请输入需要遍历的字符串")  
for i in mess:  
    print(i)
```
**range语句**（用于生成数字序列）
- 用法1:range(end)->获取一个从0开始,到end结束的数字序列(不含end本身)
	range(5)获取的数据就是0,1,2,3,4
- 用法2:range(start,end)->获取一个从start开始,到end结束的数字序列(不含end本身)
	range(2,8)获取的数据就是2,3,4,5,6,7	
- 用法3:range(start,end,step)->获取一个从start开始,到end结束的数字序列,step步长(不含end本身)
	range(0,10,2)获取的数据就是 0,2,4,6,8

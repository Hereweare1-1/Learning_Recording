# Python封装

## 1. 什么是封装

封装是将数据（属性）与操作数据的方法绑定在一起，形成一个独立的类。

## 2. 私有属性、私有方法与公共成员的区别

- 私有属性和私有方法只能在类的内部访问，外部不能直接访问。
- 公共属性和公共方法在类的内部和外部都可以访问。
- 私有属性和私有方法通常以双下划线`__`开头。
- Python没有绝对的私有机制，双下划线主要通过名称改写限制外部访问。

```
class Student:
    def __init__(self, name):
        self.name = name          # 公共属性
        self.__score = 90         # 私有属性

    def show_name(self):          # 公共方法
        print(self.name)

    def __show_score(self):       # 私有方法
        print(self.__score)
```

## 3. 私有属性和私有方法的应用场景

如果某些属性和方法不希望直接向使用者公开，可以将其设置为私有成员，以保护内部数据和实现细节。

# Python封装

## 1. 什么是封装

封装是将数据（属性）与操作数据的方法绑定在一起，形成一个独立的类。

## 2. 私有属性、私有方法与公共成员的区别

- 私有属性和私有方法只能在类的内部访问，外部不能直接访问。
- 公共属性和公共方法在类的内部和外部都可以访问。
- 私有属性和私有方法通常以双下划线`__`开头。
- Python没有绝对的私有机制，双下划线主要通过名称改写限制外部访问。

```
class Student:
    def __init__(self, name):
        self.name = name          # 公共属性
        self.__score = 90         # 私有属性

    def show_name(self):          # 公共方法
        print(self.name)

    def __show_score(self):       # 私有方法
        print(self.__score)
```

## 3. 私有属性和私有方法的应用场景

如果某些属性和方法不希望直接向使用者公开，可以将其设置为私有成员，以保护内部数据和实现细节。


# Python继承

## 1. 继承的语法

```
class 子类(父类):
    pass
```

示例：

```
class Animal:
    def eat(self):
        print("正在吃东西")


class Dog(Animal):
    pass


dog = Dog()
dog.eat()
```

## 2. 子类可以继承哪些成员

子类可以继承父类的属性和方法。

- 公共成员：子类可以直接访问。
- 以双下划线`__`开头的私有成员：也会被继承，但由于名称改写，子类不能直接访问。

```
class Parent:
    def __init__(self):
        self.name = "父类"
        self.__age = 40


class Child(Parent):
    def show(self):
        print(self.name)      # 可以访问
        # print(self.__age)   # 不能直接访问
```

因此，严格来说不能简单地说“私有成员不会被继承”，而是“会继承，但子类不能直接访问”。

# 方法重写

## 1. 什么是方法重写

在继承关系中，如果父类的方法不能满足子类的需求，可以在子类中重新定义一个同名方法，用子类自己的实现替代父类的实现，这称为方法重写。

```
class Animal:
    def speak(self):
        print("动物发出声音")


class Dog(Animal):
    def speak(self):
        print("小狗汪汪叫")
```

调用子类对象的方法时，会优先执行子类重写后的方法：

```
dog = Dog()
dog.speak()  # 小狗汪汪叫
```

## 2. 在子类中调用父类的方法

### 方式一：使用`super()`

```
super().方法名()
```

### 方式二：通过父类名调用

```
父类名.方法名(self)
```

完整示例：

```
class Animal:
    def speak(self):
        print("动物发出声音")


class Dog(Animal):
    def speak(self):
        super().speak()
        # 也可以写成：Animal.speak(self)
        print("小狗汪汪叫")
```

一般优先使用`super()`，因为它更适合多重继承，也不需要写死父类名称。

### 定义与调用
```
def 函数名(参数1,参数2....):
	函数体
	......
	return 返回值1,返回值2...
	
#调用函数
函数名(参数)
```
- 提示：没有声明函数，需要先定义再调用
	- 当有多个返回值时会封装在1个元组里
- 补充：函数round(数据，保留位数) 会把数据按传入参数保留位数
### 函数说明文档
**作用：说明函数功能、参数、返回值**
```
```
def circle_area_len(r):
    """
    该函数用于根据圆的半径，计算圆的面积和圆的周长
    :param r: 圆的半径
    :return: 圆的面积 , 圆的周长
    """
    return 3.14 * r * r, 2 * 3.14 * r
```
```
- 提示：可以通过内置函数：help(函数名)来查看函数的说明文档

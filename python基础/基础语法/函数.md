### 定义与调用
```
def 函数名(参数1,参数2....):
	函数体
	......
```

## 函数进阶
### 变量作用域
- 局部变量：在函数外定义的变量，整个文件都可以使用
- 全局变量：在函数内定义的变量，只有在函数内部才可以使用
	- 如果想要在函数内部修改全局变量 ，需要用到 **global** 关键字。
```
num1 = 1  # 全局变量
def fun1():
    global num1   # 告诉python使用外部全局变量
    num1 = 100    # 修改全局变量num1
    print(num1)

fun1()       # 100
print(num1)  # 100
```
- 如果不使用**global**，函数不能修改全局变量，此时函数内部定义的**sum1**为局部变量，和外部定义的全局变量**sum1**不是同一个东西
```
num1 = 1  # 全局变量
def fun1():
    num1 = 100    # 修改全局变量num1
    print(num1)

fun1()       # 100
print(num1)  # 1
```

### 传参方式
#### 位置传参（参数少使用）
- 调用函数时,传入的实参的顺序与定义函数时形参的顺序完全一致。
```
def add(a, b):
    return a + b
# 位置传参，按顺序赋值
result = add(2, 7)
print(result)
```
#### 关键字传参（参数多使用）
- 调用函数时,通过“形参名=值”的形式传递参数,顺序没有要求。
	**如果同时存在位置参数与关键字参数,位置参数在前,关键字参数在后。**
```
def add(a, b):
    return a + b
# 关键字传参，指定参数名字，顺序可以乱
result = add(a=2, b=7)
print(result)
# 调换顺序也正常
result2 = add(b=7, a=2)
print(result2)
```

### 默认参数
- 在定义函数时，可以直接给参数赋值，作为默认参数
```
# b设置默认值为10
def calc(a, b=10):
    return a + b
    
# 第一次：不传有默认值的参数b，b用默认10
res1 = calc(5)
print(res1)

# 第二次：传入b，覆盖默认值
res2 = calc(5, 20)
print(res2)
```

### 不定长参数（用于参数个数不确定的情况）
- **基于位置传参**
- 传入参数会被args收集并封装为一个元组
- args只是一个约定俗成的变量名，可以替换为其他的
```
def sum_all(*args):
    return sum(args)

# 调用
res1 = sum_all(1,2,3)
print(res1)

res2 = sum_all(10,20,30,40)
print(res2)
```
- **基于关键字传参**
- 传入参数会被kwargs收集并封装为一个字典
- kwargs只是一个约定俗成的变量名，可以替换为其他的
```
# **kwargs 接收不定长关键字参数，打包成字典
def show_info(**kwargs):
    print(kwargs)
# 调用，传入多个关键字参数
show_info(name="张三", age=18)
show_info(city="重庆", hobby="打球", gender="男")
```
- **位置和关键字混合传参**
```
# *args接收不定长位置参数，**kwargs接收不定长关键字参数
def mix_func(*args, **kwargs):
    print("位置参数元组：", args)
    print("关键字参数字典：", kwargs)

# 调用，同时传位置参数 + 关键字参数
mix_func(10, 20, 30, name="李四", score=90)
```
### 函数作为参数
- 提示：sclar函数中的oper参数为函数类型
```
#加  
def add(x,y):  
    return x+y  
#减  
def subtract(x,y):  
    return x-y  
#乘  
def multiply(x,y):  
    return x*y  
#除  
def divide(x,y):  
    return x/y  

def sclar(x,y,oper):  
    return oper(x,y)  
  
s1=(sclar(3,5,add))  
print(s1)
```
### 匿名函数
- 匿名函数指的是没有名称的函数,需要通过**lambda**表达式来声明函数,可以简化简单函数的编写(单行表达式)。
- 定义：lambda 参数列表:函数体
- lambda会自动将函数体的结果返回，不需要写return
```
\#lambda 匿名函数定义
add = lambda x, y: x + y

# 调用
result = add(3, 5)
print(result)
```

### 类型注解——指定变量的类型
写法：**变量： 数据类型**
```
a: int = 695
score: float = 98.5
hobby: str = "Python"
flag: bool = True
pic: None = None

names: list[str] = ["A", "C", "E"]
phones: set[str] = {"13309091111", "15209109121"}
options: dict[str, int] = {"count": 0, "total": 0}
goods: tuple[str, int, int] = ("手机", 5999, 1)

# 列表里面既有字符串又有整数
mix_list: list[str | int] = [100, "hello", 200, "world"]
```
提示：如果对变量直接赋值、变量运算等场景,Python会自动进行**类型推断**；
**Python是动态类型语言,添加的类型注解只是提示,并不是强制约束 !!!**

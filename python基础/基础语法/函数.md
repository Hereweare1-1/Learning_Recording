## 函数基础
### 定义与调用
```
def 函数名(参数1,参数2....):
	函数体
	......
	return 返回值1,返回值2...
	
#调用函数
函数名(参数)
```
- 提示：没有声明函数，需要先定义再调用
	- 当有多个返回值时会封装在1个元组里
- 补充：函数round(数据，保留位数) 会把数据按传入参数保留位数
### 函数说明文档
**作用：说明函数功能、参数、返回值**
```
```
def circle_area_len(r):
    """
    该函数用于根据圆的半径，计算圆的面积和圆的周长
    :param r: 圆的半径
    :return: 圆的面积 , 圆的周长
    """
    return 3.14 * r * r, 2 * 3.14 * r
```
```

## 函数进阶
### 变量作用域
- 局部变量：在函数外定义的变量，整个文件都可以使用
- 全局变量：在函数内定义的变量，只有在函数内部才可以使用
	- 如果想要在函数内部修改全局变量 ，需要用到 **global** 关键字。
```
num1 = 1  # 全局变量
def fun1():
    global num1   # 告诉python使用外部全局变量
    num1 = 100    # 修改全局变量num1
    print(num1)

fun1()       # 100
print(num1)  # 100
```
- 如果不使用**global**，函数不能修改全局变量，此时函数内部定义的**sum1**为局部变量，和外部定义的全局变量**sum1**不是同一个东西
```
num1 = 1  # 全局变量
def fun1():
    num1 = 100    # 修改全局变量num1
    print(num1)

fun1()       # 100
print(num1)  # 1
```

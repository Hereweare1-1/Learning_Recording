### 定义:
- 也称为网络爬虫(网络机器人),是一种按照一定的预设规则,自动浏览并抓取网络数据的程序或脚本。
- Requests库的作用是什么?
	Requests库是Python中最流行、最优雅的HTTP客户端库,让Python代码发送HTTP请
求变得极其简单
```
# 定义url  
target_url="https://www.tiobe.com/tiobe-index/"  
# 发送请求,获取数据  
response=requests.get(url=target_url)  
  
# 返回数据（还未解析，是html格式的字符串）  
print(response.text)
```
